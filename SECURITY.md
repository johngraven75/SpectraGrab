# Security Policy

## Reporting a vulnerability

Please do not report vulnerabilities through public issues or discussions. Use a private GitHub security advisory at [https://github.com/johngraven75/SpectraGrab/security/advisories/new](https://github.com/johngraven75/SpectraGrab/security/advisories/new) instead. Include the affected version, reproduction steps, impact, and any suggested mitigation.

## Supported versions

Security fixes are applied to the current default branch and released builds when practical. Reports affecting older builds may require an upgrade to a supported release.

## Disclosure

Please allow reasonable time for triage and remediation before public disclosure. The project will acknowledge validated reports and coordinate a remediation timeline through the private advisory.
